# 非原生音效篩選

直接開啟 `index.html`，不需要啟動伺服器。所有音檔維持原始內容與音量。

- 搜尋原始名稱，依來源、用途、選擇狀態或程式引用篩選。
- 點「試聽」，可循環或自動播放下一段。長音檔可用播放器拖動時間。
- 標記保留／刪除／待定、填入備註；選擇存在目前瀏覽器的 localStorage。
- 完成後按「匯出選擇 JSON」保存 `audio-selection.json`，交回處理；也可匯入繼續篩選。
- 標記刪除僅記錄意向，不會直接刪除磁碟檔案或改遊戲引用。

下載包音訊解壓至 `packs/`，檔名以封包內路徑雜湊縮短，避免 Windows 路徑過長；原始檔名、ZIP 來源、SHA-256 與引用位置記在 `catalog.json`。既有遊戲音檔及 Lentikula 以相對路徑引用。ZIP 內生成腳本未執行，來源說明與授權附件可在頁面底部開啟。

分類依檔名推測；「程式引用」是靜態路徑掃描（含機槍動態路徑），不代表所有場景都會播放。完全相同內容會標示重複，但不自動刪除。多聲道／特殊 WAV 是否可用仍以實際播放器為準。

重新盤點：在專案根目錄執行 `python tools/build_audio_review.py`。它會重建目錄清單及頁面，不會改動遊戲綁定或瀏覽器選擇。
