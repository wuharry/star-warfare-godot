# 槍械與回饋音效篩選

直接開啟 `index.html`，不需要啟動伺服器。所有音檔維持原始內容與音量。

目前只收錄槍械、換彈、彈殼、爆炸、命中／受擊／破壞與介面提示，以及最新 JSON 明確標記保留的素材。已移除未選定的交通、自然環境、人群、日常物件、配樂／預告片氛圍與其他無關音效。JSON 明確保留的腳步、冰裂、機械操作與太空船背景聲仍在清單中。

- 搜尋原始名稱，依來源、用途、選擇狀態或程式引用篩選。
- 單頁顯示全部符合條件的音效，可切換卡片／表格；頁尾可回到搜尋與篩選。音檔只在試聽時載入。
- 點「試聽」，可循環或自動播放下一段。長音檔可用播放器拖動時間。
- 標記保留／刪除／待定、填入備註；選擇存在目前瀏覽器的 localStorage。
- 完成後按「匯出選擇 JSON」保存 `audio-selection.json`，交回處理；也可匯入繼續篩選。
- 標記刪除僅記錄意向，不會直接刪除磁碟檔案或改遊戲引用。

下載包音訊解壓至 `packs/`，檔名以封包內路徑雜湊縮短，避免 Windows 路徑過長；原始檔名、ZIP 來源、SHA-256 與引用位置記在 `catalog.json`。既有遊戲音檔及 Lentikula 以相對路徑引用。ZIP 內生成腳本未執行，來源說明與授權附件可在頁面底部開啟。

分類依音檔名稱推測，不以素材包名稱裡的關鍵字分類；例如 `Chamber of Shadows` 的停屍間環境聲不會因為 `Chamber` 被歸到換彈。「程式引用」是靜態路徑掃描（含機槍動態路徑），不代表所有場景都會播放。完全相同內容會標示重複，但不自動刪除。多聲道／特殊 WAV 是否可用仍以實際播放器為準。

重新盤點：在專案根目錄執行 `python tools/build_audio_review.py`。它會重建目錄清單及頁面，不會改動遊戲綁定或瀏覽器選擇。來源 ZIP 只保留在本機，不納入 Git；重建前須依 `catalog.json` 的 `sources[].archive` 放回完整來源 ZIP。缺少 ZIP 時會停止並保留現有清單。瀏覽與試聽已保留的音效不需要 ZIP。

已執行的刪除記錄在 `excluded_audio.json`，包含來源、原始路徑與 SHA-256，本次用途清理另附刪除原因。重建時會依來源與原始路徑跳過這些音效，避免從保留的來源 ZIP 再次解壓回來。來源 ZIP 與授權附件保留。
