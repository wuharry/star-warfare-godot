座標如何還原

從 SW1 resUI.bytes 的 vUI[11]（商店）、vUI[13]（道具）、vUI[19]（導覽列）讀取 module；把 Unity 左下原點轉成 Godot 左上原點。滑動規則對照 UIScroller、UISliderTag、UISliderAvatar、UISliderProps。中央角色使用現有模型重新取景，沒有把商品格縮窄充當手機版。
