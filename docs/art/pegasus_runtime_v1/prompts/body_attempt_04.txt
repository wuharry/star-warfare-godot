Asset type: opaque flat diffuse/albedo UV atlas for an existing skinned game armor material.

AUTHORITIES AND GOAL
The first reference is the immutable original-game atlas: it fixes UV island positions, outlines, scale, orientation, padding and the actual mesh sampling layout. The latest armor concept and any separately specified latest helmet reference fix design identity. Other approved runtime Viper/Fortune atlases fix the shared hand-painted visual language only; do not copy their identifying color or panel designs. Actual mesh-derived UV guides are technical references, never output colors. A whole-body concept is not itself a usable atlas.
Create a complete game-ready texture by painting the approved design into the existing original atlas. Retain recognizable differences among armors: dome, visor, guard, shoulder layers and color blocking. Reconstruct each part within the actual UV charts rather than drawing a second character or repacking charts. A newer helmet-only reference overrides an older body concept for the head alone.

SHARED VISUAL LANGUAGE
Use broad, softly shaded hand-painted armor planes, restrained edge accents and sparse corner wear. Retain readable dark cloth around human joints, separate helmet glass from opaque framing, and keep clear major color blocks at gameplay distance. Match current Viper/Fortune in contrast, highlight size and detail density while keeping this armor's approved identity. Avoid dense cracks, uniform bright white outlines, chrome, photographic reflections, high-frequency noisy wear or flat solid-color placeholder shading. Glass uses a controlled broad reflection without excessive bloom or multiple bright center columns.

UV AND GEOMETRY CONTRACT
Keep every original island in exactly the same normalized location, outline, orientation and scale. Preserve padding and mirrored joining-edge continuity. Do not repack, split, merge, rotate or invent islands. A mirrored shared join must not be painted as a dark exterior border. Paint design changes only within the actual relevant charts; do not transfer a helmet vent onto an ear or a forehead onto the rear.
The asset pipeline separately fits the existing head geometry where needed. Total differences must be measured against this armor's true original glTF source, not against another armor or an intermediate candidate. The allowed ceiling is 20% for original-normalized displacement, per-axis dimensions, gray silhouette difference and changed UV-coordinate fraction per material. This is a maximum engineering budget, not an additional20% per pass, an image-similarity score or a repaint-area restriction. Preserve original vertex/UV coordinate/chart counts, triangle indices, Skin binds, 28-bone rig, bone names, weights, transforms and original animation tracks. Prefer unchanged UV coordinates; only apply measured local changes if actually needed. Keep body/limb geometry unless a necessary design correction is separately measured and recorded. Do not change armor IDs, gameplay statistics, skills, inventory or backpack routing.

NATIVE OUTPUT
Return only the full edited flat opaque square atlas at the target framing, retaining opaque padding and island outlines. No perspective, character render, turnaround, rearranged art sheet, technical lines/colors, captions, text, logos or watermark. Use painted brightness suitable for the existing unshaded diffuse material; do not rely on metalness, normal or roughness maps. Save all raw native generation attempts and copy selected PNG bytes unchanged without post-generation painting, tinting, cropping or resampling.

Save this entire base plus the exact armor/material addendum as the actual prompt sent.
