THUNDER / HELMET STUDIES V5

藍色頰甲向內收，面罩下端變窄

依照圈選的概念圖，修正面罩與眉甲的輪廓。A 從 SW2 連續網格調整；B 保留早期雛形的圓頂與中央脊甲，重做梯形面罩和包覆頰甲。兩版使用相同身甲、姿勢、燈光與取景，圖片直接由 Godot 的遊戲角色擷取。

點圖片可放大。面罩刻紋沿用配對素材；新增的頰甲、眉甲厚度與收窄輪廓都是模型幾何。

兩版改動與遊戲切換
部位A · SW2B · 雛形
頭盔外殼保留 SW2 分件、耳部與板線；頂部改為連續圓弧，已確認的面甲保持不變。保留原雛形圓頂、寬脊甲、側面板線及後腦。
金色面罩變形原連續網格，讓下半部向中央收窄，保留原 UV 與弧形紋路。新建上寬下窄曲面，配對金色紋路與法線；藍色頰甲包住兩側。
呼吸器縮薄、沿下巴斜面嵌入；移除額外側接片並收進原模型底座，保留凹入通氣口。保留既有凹入通氣口與斜面外殼。
藍色配色外殼採身甲相同的藍／深藍基色，保留貼圖板線與磨損；金色面甲不調色。保留既有配色。
整套模型三角形12,66239,238（包含原雛形的圓頂細分；此數字不是效能量測）
身甲／動畫沿用現有 Thunder 身甲與原角色骨架；兩版均由遊戲及商店共用的裝甲載入器套用。

從專案根目錄執行以下任一指令即可開啟遊戲。這只選擇本次啟動的頭盔版本；裝備 Thunder 頭盔後即可查看。

powershell -ExecutionPolicy Bypass -File tools/thunder_helmet_comparison/launch.ps1 -Helmet prototype

Godot 編輯器也可在執行參數加入 --thunder-helmet=prototype 查看 B；移除參數會使用 A。
