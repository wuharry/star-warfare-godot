# Fortune v7 頭盔修正前快照

此目錄保存僅修改貼圖的 v7 遊戲素材與當時的 PASS 證據。當時未新增模型或 UV 改動，但頭盔美術未通過使用者確認；之後的頭盔形狀修正不得沿用這個零改動結論。

- `review/`：當時三版頁面的 15 張調整後 Godot 擷取。
- `delivery/`：SCN、GLB、packed master、target、geometry 與當時 manifest。
- `atlases/`、`prompts/`：五張實際貼圖與實送 prompt。
- `reports/`：當時模型、動畫、貼圖、擷取與網頁驗證報告；報告內的原始 canonical 路徑屬歷史資料，應搭配本目錄快照檢查。
- `snapshot.json`：各檔來源、SHA256 與大小。

原版、最初 `before/fortune`、Viper 及 canonical 檔案均未改動。後續版本請另存新目錄，不覆寫此快照。
