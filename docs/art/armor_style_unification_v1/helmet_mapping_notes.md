# 頭盔生成前必核對的 UV 定位

2026-10-04，Fortune 的第二個頭盔修正稿把藍眉留在後側、前眉畫成綠色。原因是依 atlas 外觀猜測前後位置；現有原版 UV 的前眉在主島左上斜帶，圖面右側的延伸反而是後側。後續提示词必须依原模型頂點／三角面的 UV 和實機投影確認位置，不可只憑貼圖看起來像正臉就判斷。

- Fortune 原前眉中央頂點 UV 約 `(0.286, 0.0733)`，轉角約 `(0.3778, 0.2147)`；對應 `guides/head_semantic_authored_v4c.png` 的淺藍區域。生成時保留實際前眉範圍，再用實機正／側面確認。
- 原耳側頂點在 rest space `x=±0.2538, y=1.6345, z=0.0286`，UV 約 `(0.6459, 0.4869)`。耳罩陰影只能畫在現有側面板，不能稱作新增耳罩幾何。
- 紫色島左邊約 `u=0.55` 是正臉中央鏡像邊，並非面罩外框；此處需要連續紫色及取樣外延，不能畫黑框、直亮條或鼻尖。真正外框在面罩上側及圖面右側。
- 模型改形仍以真正原版計算總 15% 預算；前版只是用來量新增差異，不能把兩輪額度相加。UV 數量、charts、拓撲與權重保持原版。

這些位置只適用 Fortune，修正前後方向的實送提示詞為 [v10](../fortune_runtime_v1/prompts/head_diffuse_refinement_v10.txt)，後續收斂高光的提示詞為 [v11](../fortune_runtime_v1/prompts/head_diffuse_refinement_v11.txt)。其他裝甲必須由自己的 UV 與實機圖重新定位。

v11 提示詞亦嘗試處理後腦中央暗縫，但試貼中仍可見；不可因 prompt 写了「移除」就把結果記為已修復。必須以正式資源截圖確認，保留仍未完成的項目。
