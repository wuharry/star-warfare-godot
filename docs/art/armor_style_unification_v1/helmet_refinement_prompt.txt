Use case: precise-object-edit (production helmet atlas refinement)
Asset type: flat diffuse/albedo UV atlas for an existing skinned game helmet.

STAGE AND AUTHORITY
This is an explicitly requested helmet-design correction after a surface-painting pass. The approved helmet reference defines the desired design; the current atlas and semantic guides define the exact existing UV layout. The rejected current runtime image explains the defects to correct, not features to preserve indiscriminately. Original-game images define broad hand-painted rendering only. Do not copy obsolete original helmet details.
The image output changes helmet paint only. Local vertex shaping is performed separately by the game asset pipeline and measured against the true original source, with total displacement, dimensions and silhouette each within the existing 15% contract. That is a total engineering budget, not an additional allowance, texture repaint limit or art-similarity score. Retain original triangle indices, coordinate/chart counts, skin, bones, weights, tracks and armor ID. No extra UV edits are allowed in this correction; preserve the already-authored atlas sampling exactly.

PAINT AND UV RULES
Return the edited opaque square atlas only, in exactly the target's framing and orientation. Preserve every island's positions, silhouette, scale, rotation, mirrored sampling edges and padding. Internal paint/color boundaries may be redesigned only where the per-asset addendum explicitly requires it. Never repack, merge, split or invent islands. No character illustration, turntable, background scene, labels, grids, technical guide colors, triangle lines, text or watermark.
Use broad, controlled hand-painted light and shade, restrained color-tinted edge accents and sparse corner wear. Do not paint fine white outlines around all plates, noise, dense scratches, cracks, chrome or false thickness. A painted highlight is visible in the unshaded game material, so keep it subdued rather than depending on roughness/lighting to fix it.
Keep visor glass a continuous dark colored surface with one soft broad reflection. Respect the actual frontal mirrored seam: never outline it or place a bright stripe there. Avoid two bright columns, eye pairs, a black center split, sharp W shapes, triangular nose decorations or pink bloom. Glass perimeter/gasket is allowed only on actual external edges, not a shared frontal center seam.
Retain neutral dark neck cloth. Do not create protruding machinery, horns or a new independent ear object that the existing geometry cannot support. Compact ear-cover shading may be painted on an existing side panel and must be described honestly as texture detail.

REQUIRED RECORD AND ACCEPTANCE
Save this complete base plus the actual per-asset addendum, every attempted raw output and immutable input snapshots with SHA256 and role. Copy the selected native PNG bytes without postprocessing. Apply it to the real skinned model before accepting it. Inspect front, quarter, side, rear, gameplay scale, idle, run and reload; check mirror continuity, stretched paint, chin/crown proportions and preserved identity. Measure shape against the original and record incremental changes against the rejected revision separately. Engineering PASS is not user approval of the helmet design.
