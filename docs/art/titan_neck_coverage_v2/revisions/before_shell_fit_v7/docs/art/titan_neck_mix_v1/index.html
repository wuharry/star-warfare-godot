後續頭盔製作的必要條件

頸管是跨裝甲接口。搜尋真原版的所有 mesh surfaces，從實體連通部件與骨骼名稱辨認接口，保護所有 UV 接縫重複頂點；位置、UV、三角形、骨架與權重都必須原樣保留。整體 15–20% 的形狀預算不能用來移動這個接口。

共享編譯器與 Titan 專用編譯器已加入保存前 gate，接口與不透明是硬條件。非法數值會在 ArrayMesh 上傳前被拒絕，parts 與三角形數量在寫入前檢查。黑布色調是依設計啟用的條件，Titan 始終嚴格檢查，其他設計保留其核准底色。其餘自訂編譯器尚未全部接入，不能把本輪結果當作全專案既有素材都已通過。

Titan 內襯須在原生貼圖內保持不透明的黑色布料，不能用材質染黑或衣領掩蓋。建置、正式 SCN／GLB、負面測試、全 29 身甲的實際姿勢與正常引擎近景都須驗證；工程通過後，使用者仍可繼續調整外觀。
