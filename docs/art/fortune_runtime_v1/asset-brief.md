# Fortune 製作規格

- 對應原遊戲 Fortune ID 01、概念 C-02；保留 head/body/arms/legs 裝備 ID 與原四部件節點。背包本輪沿用原裝備掛點。
- 頭盔以本輪使用者附圖 `approved_helmet_reference.png` 為最高造型依據；舊 `c02_fortune_fusion.jpg` 保留作歷史參考。採圓綠穹頂、水平狹窄銀藍眉帶、完整紫色折面面罩、小藍下唇、綠色實心短面甲與小側縱槽。
- 頭部 atlas 大幅重畫；清除舊額徽、眉上兩孔、中央 V 暗縫、藍鼻甲與中央橫 vent。紫 atlas 的左緣是左右鏡像共用的正臉中央，不能畫黑 gasket 或兩根直白亮柱；頸部改成中性黑色細橫 rib。
- 身體保留橄欖綠中央胸甲，銀藍 U 框沿外側向下連接胸下緣；清除原銀藍中央縱線，避免套上模型後變 Y 形。
- 五個 diffuse 為不透明 sRGB 手繪 atlas，使用 Godot 原版 unshaded 呈現方式；不是概念圖、三視圖、PBR 材質球或透明護目鏡。
- 頭部局部改形保留圓頂弧度、拉平兩圈前眉以形成薄 lip、弱化紫面罩中央鼻突、實際縮短並內收前下顎；neck attachment 保持原版。頂點最大位移以原最小頭尺寸正規化為 14.3263%，不是在前一稿形狀上累加 15%。
- 原模型決定短壯遊戲比例、背面、關節、武器及背包掛點；同一套素材支援原待機、跑動與換彈。
- 每材質改動 UV 座標占比、部件尺寸差異、頂點 rest 位移占原最小尺寸比例、四向灰模輪廓差異皆不得超過 15%；UV 座標／分區數量、原索引及骨架權重完全相同。
- `guides/*_front_regions.*` 從原模型位置投影，指定正面額甲／胸框真正採樣的區域；技術線、色區、文字不可出現在 canonical diffuse。
- `head_semantic_*_v4c.*` 使用最終改形後的三角面與 UV 取樣；`head_visor_neck_semantic_v6.*` 專門標示紫面甲中央鏡像邊與黑頸區。紫色主面 u=.548–.69／v=.707–.977 保持連續，深紫側折面只放 u≥.70。生成 guide 版本分開保存，原 UV guide 不覆寫。
- 最終驗收使用共用遊戲／商店載入器與正常 resource 匯入；保留原稿及試貼圖片供比較，不把 draft-only preview 當作遊戲交付證據。
