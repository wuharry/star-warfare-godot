## 目標與範圍

2026-09-11：依 Harvey 選定的 Viper／Assault 概念質感，為 ArmorCatalog.SET_NAMES 的 29 套人物裝甲製作設計圖。每套包含頭、身、手、腿；背包商品、武器與怪物不在本批範圍。

使用內建 imagegen，一套一個獨立生成請求。00 為使用者要求保存的先前概念圖，其餘以它為風格參考，不把舊版 UV 貼圖重新換色。

## 規則與驗收

- Star Warfare 緊湊比例；頭盔有切面、凸起眉骨、內縮面罩、凹入感測器與厚下顎。
- 硬質甲片有厚度、倒角、分件與活動間隙；金屬塗裝與暗色柔性關節區分。
- LED 少而有用途；不滿身霓虹，不堆刻線；頭盔優先、胸甲其次。
- 各套用不同頭盔、胸甲、肩甲結構區別，不只换色。
- 大全身前視、頭盔特寫、背面共同驗收。概念圖不保證多視角幾何完全一致，建模前仍需結構校對。
