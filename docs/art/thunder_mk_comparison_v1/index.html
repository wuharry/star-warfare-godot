來源、限制與接續方式
  • mk1 色系取自實際載入的 assets/equipment_refined/armors/armor_06.scn 與其貼圖；不是尚未接入 runtime 的 redesigned_armors 藍青版，也不是前一批概念圖。
  • mk2 來源 commit：252aab1b38d0298994053ffaaec39677ef1ae4ee。同名 OBJ / PNG 在已測 UV 翻轉與鏡像條件下仍無法正確對位，且未附完整材質設定，因此使用灰模作幾何參考。這不代表已判定來源檔損壞。
  • mk1 由 Godot OpenGL Compatibility 截取；mk2 灰模由 Blender 渲染，攝影與燈光不同，不能當作相同光照下的材質量測。
  • 候選圖使用內建 imagegen，僅供決定配色與造型。A 不是已烘焙的新 UV，B 不是已完成新模型；多視角、動作與穿模仍待後續驗收。
  • B 新頭盔依你提供的圖片調整：寬厚中央甲脊、下壓眉甲、V 形橘色面罩與短下巴模組。這次修改目標是頭盔，身體沿用舊硬甲候選；生成結果仍可能有非頭部細節偏移，請用「舊頭盔」切換比較。
  • 素材來源與商用授權另行處理；AI 改作不代表已清理原作品權利。
