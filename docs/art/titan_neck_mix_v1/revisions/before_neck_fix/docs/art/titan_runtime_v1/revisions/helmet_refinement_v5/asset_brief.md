# Titan v5 · 玻璃、冠部與護框打磨

本輪目標是把 v4 已有的大面罩打磨成連續琥珀玻璃，收整冠部、耳側與下護框，讓頭盔更接近已指定的概念。v4 的正面覆蓋門檻通過不代表概念外觀完成；尤其金色面甲仍偏不透明、冠部與耳側甲片較硬。

採用流程先凍結 v4，再生成可套用原頭部 UV 的原生 diffuse，調整既有頭部座標，重新匯入正式遊戲素材並擷取。肩、胸、手、靴四圖、非頭部模型、遊戲 ID 5、獨立背包與 28 原骨架保留。

## 必要後續 prompt 條件

- 先檢查實際模型的正、斜、側、背面，確認貼圖在 UV 上的取樣位置；概念圖只定義設計外觀，不能當作整張 diffuse 套圖。
- 面罩是一整片圓弧琥珀玻璃。使用柔和寬反光與深淺過渡，避免畫成雙眼、左右各一個白色高光、中心鼻梁或不透明金屬板。
- 頭冠採較克制的鋼藍甲面，寬漸層與少量邊緣磨損；避免高飽和青藍、細白描邊或新增密集刻線。
- 護框保持連續，耳側不要形成大型突出方片。既有 UV 鏡像會複製裝飾，不能把單一中心扣具畫到會鏡像成雙扣的位置。
- 保留原遊戲厚甲與短比例，不藉成人全身概念圖把整套模型拉長；Viper／Fortune 的大色塊與手繪塑形是系列畫法基準。
- 頭部沿用 164 三角形、334 UV 座標、3 個連續 UV 區域；10 個原 UV 改動仍計入原 294 座標。不得以新版本為由重置真原版總 20% 形狀或 35% 頭部計數上限。
- 原生 PNG 全尺寸保存，完整實送 prompt、全部候選與輸入／輸出 SHA 可追溯；不用程式重畫、改色、縮放或合成美術。

## 驗收

驗收必須使用本輪最新 SCN、GLB、packed master 與正常引擎資源。檢查 15 個 runtime 姿勢、9 個 GLB 姿勢、五張貼圖 RGB、UV／拓撲／權重與防護、四向灰模、64 張擷取及真實存檔不變。

面罩可見琥珀玻璃至少佔整個頭盔 mesh 正面投影 50%，分母包含該 mesh 的頸部。這只是覆蓋比例，不能當作圓度、風格相似率或使用者接受。側後方仍依原頭殼推定，手機效能與使用者美術接受須分開記錄。

本輪工程報告 PASS：採用原生 attempt 3，頭圖與生成輸出位元組相同；15 個 runtime、9 個 GLB 姿勢、五圖與 packed master、契約／防護及最新正常資源 64 圖均已核對。UV 與 v4 完全相同；原版總位移 19.4967%、四向整體灰模最大差 3.7609%。正面玻璃投影為 58.0930%，達到 50% 門檻。

實際觀察：attempt 1 的雙亮斑及 attempt 2 的上緣分塊反光已再修整；本輪採用 attempt 3 的較寬連續上緣反光與細橫線。低面數冠頂、側板與推定側後方仍保留，沒有概念中的獨立圓耳或中心單銀扣。使用者美術接受與手機效能仍為 NOT RUN；工程 PASS 不等於完美。
