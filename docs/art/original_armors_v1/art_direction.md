# 本輪美術方向

目標是「人穿著厚實科幻裝甲」，並讓每款能看出原版與指定 Halo 設計如何融合。主甲片保持大面積可讀輪廓，布衣頸、腋、肘、腰、膝與正常五指手套表明裡面是人。

## 如何融合

原版模型實際觀察 → 保留配色及二至三個辨識線索 → 借用指定非士官長 Halo 的頭盔、護頰、肩胸或背部結構 → 重組板件接縫與比例 → 目視檢查 → 後續建模。

- 原版提供身份。例如 C-01 保留 Viper 的鋼藍、紫玻璃、黑冠槽與双胸斜窗；ODST 提供短眉沿、护頰和肩帶層次。
- Halo 供體逐款具名，不能把任意「Halo 風格」當成已核對設計；沒有看到的背面就標未觀察，新增結構明確列為本輪設計。
- C-06／Titan 的最高優先參考是使用者兩張頭盔附件的大弧面金玻璃方向。概念呼叫沒有附上 Titan 原圖或本地 EVA 圖；後續圖種可以使用已生成概念與獨立背包稿，必須逐次記錄。
- 胸腰與關節按人体活動分開；頭部維持連續玻璃面窗與完整護頰，不用鏡頭眼或骷髏機械嘴取代。原版長角、肩翼和尖片可縮短，保留方向與數量線索。
- 不再套用舊的全系列白綠配色或固定機械頭。每款色票依原版身份重列；JSON hex 是美術近似值，不是取樣貼圖值，也不要求全系列只有四種色系。

## 圖稿分工

| 稿件 | 提供內容 | 仍需後續確認 |
|---|---|---|
| C concept | 單人全身、頭盔與配色定向 | 最終比例、使用者選稿 |
| C turnaround | 正面／左側／背面與可選獨立背包示範 | 正交校正、遮擋、左右及掛點 |
| C construction | 頭盔、肩與背部裝配拆解 | 真實厚度、鎖扣、拆卸順序 |
| B design_sheet | 背包主3/4、外向、側面、貼背、維修零件 | 肩帶長度、重量分布、碰撞與模組間隙 |

同序 C／B 只是图稿搭配。C-01 對應 Viper，B-01 對應 VB-03-II，B 可和其他 C 混搭；裝甲技能不寫入背包能力。背包需保留原款雙筒、圓盤、飛翼、三芯或框架差異，不做同一箱體換色。

## 完成度與來源

`generation.records` 是實際呼叫與目視紀錄；`source_references` 是研究參考，兩者不能互相冒充。C-06 的兩附件無本地來源檔，據實標示；其餘檔案使用 `references/` 的實際圖像。未採用稿保留完整提示詞與版本紀錄，不能計入完成數。

三視與拆解只提供近似結構，不能直接拿來當 UV 貼圖或宣稱已有可用遊戲模型。所有技能仍為 `proposal_only`；圖稿融合和優化也不代表来源素材已取得授權。
