## 從圖到遊戲素材

```text
概念／三視／結構稿
        ↓
獨立製作新的3D網格（真正的外形、甲片厚度與關節間隙）
        ↓
展開UV（每塊模型表面對到貼圖的哪個位置）
        ↓
依新UV繪製專用底色、粗糙度／金屬度與需要的法線貼圖
        ↓
綁定骨架、設定權重與裝備接點
        ↓
接回裝備系統，測試混搭、跑步、射擊、換彈與場景光線
```

概念圖不是可直接「捲到人物上」的 UV 貼圖。只有換貼圖，舊模型的頭盔、肩甲和輪廓都不會改變。未取得授權的路線以新網格與新貼圖為目標，不以原模型重繪當成已完成替換。

### 建模交接

| 項目 | 要求 |
| --- | --- |
| 外形 | 大左肩、雙層小右肩、斜胸甲、封閉三鏡頭面甲；左右均以穿戴者為準 |
| 部件 | 頭、身體、手臂、腿與獨立背包；延續程式的裝備責任，不必沿用原美術資產 |
| 對接 | 最終接回 `ArmorHead_00`／`ArmorBody_00`／`ArmorHand_00`／`ArmorFoot_00` 與背包接點；C-01 是設計代號，目前沒有另增 runtime ID |
| UV | 新模型完成後才定稿；左右肩不得共用鏡像島，鏡頭／發光區與布料要可獨立控制 |
| 厚度 | 靠網格與倒角呈現，底色保留手繪質感；不把重陰影全部畫死在貼圖上 |
| 動作 | 肩肘、髖膝活動空間以實際姿勢驗證；圖上的轉軸是構想，不是機械施工尺寸 |
| 視圖 | 三視稿有近正交透視與小細節差異，需在建模中對齊；不是工程精準三視圖 |
| 骨架與動畫 | 相容程式接口不等於已有素材權利；新分支仍需確認或替換骨架、動畫及其他繼承資產的來源 |

技能在 [C-01 資料](c01_breakwater.json) 中全部標示 `implemented: false`。HP／盾使用現有入門裝甲作提案比較基準，並未改動遊戲數值；主動技能的冷卻、角度和減傷是待實測的設計值。
