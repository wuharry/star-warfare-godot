C-01 堤衛BREAKWATER

把入門通用裝甲重新設計成殖民地搶修隊的防護服。封閉三鏡頭面甲、不對稱大左肩和斜向胸板建立新的辨識輪廓，保留厚甲切面與短壯手繪質感。

原創方向｜待美術選定概念與設計稿已生成模型／UV／技能尚未實作四個色系

用大甲片建立厚度

堤衛的防護輪廓來自完整面甲、寬左肩與交疊胸板。手肘、手腕、髖部和膝後保留黑色活動間隙，後續由真正的模型厚度與倒角呈現光影。

  • 頭盔：低平梯形封閉面甲，穿戴者右側三鏡頭、左下斜進氣柵。
  • 胸肩：左肩整塊寬甲，右肩兩片疊甲；胸口為斜向交疊的兩個色塊。
  • 腿與背包：方膝甲、寬脛甲、獨立後跟；矩形補給包以橘色提把識別。

角色定位：入門與守位

原為殖民地搶修隊的量產防護服。左肩承受碎片、斜向護板方便更換，外置電池讓長時間巡防不必反覆卸甲。

三視設計稿補足側面與背面

正面、穿戴者左側與背面使用同一套零件語彙；背包獨立拆裝，方便日後與其他裝甲混搭。

結構草稿說明零件如何分開

面甲、肩甲和背包先各自建立結構。黑色內襯與活動間隙需要保留，不能把所有零件做成一個不動的外殼。

整備回充

完整四件、存活且連續六秒未受傷後，每秒回復最大護盾的 20%，回到上限即停止。

  • 再次受傷便重設等待；卸下任一部件後停用。
  • 不回生命、不提供無敵，也不和同名模組疊加。
  • 沿用「離開交火才能回盾」的通用玩法，後續需改成適用原創裝甲的能力介面。
OPTIONAL ACTIVE · PROPOSAL

定步護屏

後續解鎖的主動模組：三秒內，正前方 120 度的直接命中傷害降低 20%，同時移速降低 25%；啟動後開始十八秒冷卻。

  • 背後、地面酸液與持續傷害不減免；死亡或卸裝即終止。
  • 射擊與換彈照常；左肩前傾、橘色安全扣閃亮提示狀態。
  • 以移動代價換短暫容錯。需要新增方向判定、動畫與冷卻邏輯。
