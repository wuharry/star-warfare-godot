玻璃質感、冠部與護框打磨

v4 的面罩大小已達工程門檻，但玻璃讀成較不透明的金色板，冠部與耳側護框仍較硬。本輪從固定 v4 出發，修整原生頭圖與既有頭部形狀；肩、胸、手、靴四圖、非頭部模型與 28 原骨架保留。

目標：一整片圓弧琥珀玻璃，至少佔整個頭盔 mesh 正面投影 50%。 分母包含該 mesh 的頸部；覆蓋比例不是圓度、風格相似率或使用者美術接受。

持槍、跑動與遊戲場景

遊戲場景是停止戰鬥的鏡頭擷取。本輪上緣反光更連續、細橫線更克制，耳側與下框稍收；仍可見低面數冠頂和側板切面，沒有概念中的獨立小圓耳與單一中心銀扣。原遊戲短比例保留，側後方由斜視概念及原頭殼推定，不宣稱完美或逐像素還原。
