# 裝甲概念圖落地盤點

2026-09-12。依據 commit `068f4785eee8542217b2e0a3ab4f72b16056f5bf` 的 v2 概念候選，以及目前遊戲實際使用的模型與程式。

目前方向是**以各套原模型為底細修，保留原本辨識特徵**；v2 概念圖用來參考接縫、邊緣與表面質感。Viper 已完成第一套可玩細修樣板，見 [製作說明](armor_rework/README.md)；其餘 28 套仍是後續盤點。

## 原素材可以保留什麼

| 項目 | 實際來源／證據 | 製作方向 |
| --- | --- | --- |
| 29 套裝甲、四部位分件 | `scripts/core/armor_catalog.gd` 的 `SET_NAMES`、`PART_KEYS` | 保留頭、身、手、腿的換裝接口，共 116 個部位；不能把新裝甲全合成一個不可混搭的模型 |
| 原版 21 套網格與骨架 | `assets/models/player/animated/player.gltf` | 以原骨架、關節位置和現有網格作比例與活動空間參考；輪廓差異大的硬甲重建 |
| 額外 8 套遊戲裝甲 | `assets/callOfMini/gameplay/*.scn` | 已接到原玩家骨架；沿用同一骨架契約，逐套處理新外殼 |
| 換裝時選取網格 | `scripts/game/player.gd` 的 `_apply_recovered_armor_visibility()` | 保留部位命名與 visual_id；讓遊戲與商店選到同一套資產 |
| 商店預覽 | `scripts/ui/unity_equipment_shell.gd`、`tools/render_armor_thumbnails.gd` | 和遊戲共同使用 `armor_visuals.gd`，重製後重新擷取商品縮圖 |
| 原版材質恢復 | `scripts/game/armor_visuals.gd` 的 `_restore_original_materials()` | 原版 00–20 會被設成 `SHADING_MODE_UNSHADED`。新材質須有明確分流，才能保留金屬反光與法線細節 |
| 既有重設貼圖工具 | `tools/generate_redesigned_armors.py` 的 `transform_texture()` | 現有方法是依亮度換色與疊加圖案，沒有重建網格；不適合作為這批概念輪廓的完成品 |

讀取原 glTF 索引得到 Viper 的頭／身／手／腿分別為 136／298／112／136 個三角形；Tank 為 206／338／116／136。這是來源網格實際計數，不是效能量測，也不構成新模型的面數預算。

## 每種差異如何製作

| 概念圖差異 | 要改的資產 | 專案例子 |
| --- | --- | --- |
| 大輪廓、厚度、遮擋與真正空隙 | 3D 網格 | Tank 的厚綠領環、Viper 的內縮面罩、Wrath 的離體頭環 |
| 顏色、分色、輕微刮痕 | Base Color 貼圖 | Tank 的藍灰殼與橄欖綠護環 |
| 不影響輪廓的細小凹槽 | 法線貼圖，必要處再用網格 | 螺絲槽、淺刻線；厚甲邊缘仍要實際幾何 |
| 金屬與橡膠的反光差異 | Metallic／Roughness 材質資料 | 硬甲高光、手肘暗色柔性內襯 |
| 局部燈芯 | Emission 遮罩與強度 | 頭盔感測器小窗；不讓整片甲殼一起發光 |
| 彎手與跑步時的形變 | 骨骼權重與活動間隙 | 肩甲隨上臂移動，關節內襯可彎，硬甲不能像布一起捲曲 |

新網格先確定分件與 UV（表面攤平成貼圖的位置），再製作最終貼圖。概念圖裡的攝影棚光影不應直接烙在 Base Color 上。保留關節位置有助於沿用現有動畫；若改長手腳或肩寬骨架，還要重新處理持槍、換彈與動作對位。

## 製作與驗收順序

先讓一套新裝甲在實際遊戲鏡頭下成立，再將已验证的分件、材質與骨架流程用於其他套裝；每套輪廓仍單獨製作。

```text
v2 概念＋原模型／骨架
    → 統一前側後結構、比例與分件
    → 製作新外殼網格、UV、骨骼權重
    → 生成及整理貼圖，設定 Godot 材質
    → 遊戲與商店接線、重新擷取縮圖
    → 站立／跑動／飛行／持槍／換彈／混搭驗收
```

樣板建議選 Viper：它已有保存的風格基準，也是預設角色，可以最早發現材質、相機距離與持槍問題。之後用 Tank 驗證重甲空間，再用輪廓特殊的 Wrath 驗證頭環與肩甲。此順序是製作建議，尚未將候選圖標為美術定稿。

驗收須使用實際遊戲 renderer 和地圖照明，另外保留中性光源的轉台比較。測試包含套裝整套和跨套頭身手腿混搭、頭肩遮擋、槍托與前臂穿模、背包空間、新材質不被原版 unshaded 邏輯覆蓋。面數、貼圖大小和材質數預算需在樣板載入後量測，不先宣稱效能不受影響。
