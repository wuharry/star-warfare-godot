驗證與來源

桌面 UI 互動、購買與指定欄位裝備、手機商店、手機裝備與背包測試均 PASS。桌面畫面以 Godot 4.7.2 Compatibility / OpenGL 3.3、RTX 4080 Laptop GPU 取得。

寬版截圖 1280 × 720；縮窄版與手機對照 1080 × 720（遊戲邏輯畫布 960 × 640）。測試使用隔離存檔。

CommonUI 的命名區域來自已提取的原始 XML，共 87 個。貼圖 PNG 未重畫，桌面版適配集中在 recovered_armory_skin.gd；手機版仍使用原先的 SW1 版面。

Harness 檢查仍有既有的 generated drift，與本次遊戲 UI 驗證分開記錄。未執行 Android / iOS 實機及打包版本驗證。
