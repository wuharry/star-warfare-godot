需要注意的細節

  1. 只有 beam 會貫穿。player.gd 的 _fire_hitscan() 裡 pierces 的條件是 kind == "beam"，而 beam 只有 gun21 Laser Cannon 一把。 gun17／gun18 的 laser kind 打中第一個目標就 break。
  2. 持續傷害區只接了兩個地方。OriginalWeaponArea 只由 fly_grenade（gun45） 和 gun41 的 joke_variant == 2 建立。描述裡同樣寫「pollutes a small area」的 gun20、gun31、gun44 都沒有接。
  3. 多發分支只有兩把。_fire_projectile() 的 directions 陣列只對 gun29（3 個方向）和 gun42（5 個方向）展開。gun30 描述說三發，實際走單發路徑。
  4. 全專案沒有充能，也沒有緩速。charge 與武器用的 slow／stun 都查無實作。gun21 的「5s cool down」與資料裡的 0.2 秒差了 25 倍。
  5. gun14 與 gun15 的範圍半徑同為 3.0，描述卻分別寫「not bad splash radius」和 「low splash radius」。不是實作錯，是兩條描述對同一個數字給了不同評價。
判定只涵蓋描述裡可驗證的機制主張。傷害／射速／能量的高低屬於相對形容，數值順序經核對後方向一致，不列入對錯。 POW／FIRERATE／ENG 沿用遊戲商店介面自己的欄位名；FIRERATE 欄位在原版顯示的是冷卻秒數，數字越小越快。
