# 保留、修改與未接入

本輪針對現有遊戲可對應的裝備和事件套用來源資料；解析整個包，不代表把三個遊戲的規則全部混成一套。

| 系統 | 保留 | 修改／新增 | 尚未接入 |
| --- | --- | --- | --- |
| 武器 | SW1 47 把原傷害／射速／能量／價格；既有換彈姿勢 | 核對最新提供 APK 資料一致 | SW2 的 34 列武器與 CoM 其他槍型；未憑表新增模型或射擊行為 |
| 裝甲 | SW1 裝甲數值與既有高清貼圖／模型 | CoM 8 套來源基礎屬性、整套購買、分件混搭、護盾恢復 | CoM 職業套裝、完整升級／特殊被動；SW2 未核實欄位不寫入現有裝甲 |
| 怪物 | 現有 4 類生成／AI、原數值與既有倍率 | 驗證 SW1 15 列怪物資料一致 | 原作所有 Boss 招式、SW2 任務／載具、CoM 全訓練模式 |
| 成長 | SW1 軍階、現有經驗與存檔金額 | CoM 解鎖用的經驗換算；舊 CoM 部件所有權升成整套 | 線上賽季、排行榜、公會與伺服器動態設定 |
| UI | 目前商店排列、高清圖示與雙語框架 | 原 CoM 整套圖示、護盾數值、來源等級、整套價格說明；移除過時的「XP 尚未實裝」標示 | 原作所有 UI 流程的逐頁重製 |
| Audio | 已在正式路徑的相同聲音 | 補齊唯一 PCM，建立可試聽且遊戲可載入的 catalog，接入現有 CoM 事件 | 不存在的原作角色／技能不硬配觸發 |

例如 Thunder 採用了新版頭盔美術，也不因此改成 SW2 的另一套裝備平衡；來源身份、外觀版本與 runtime 數值是三件可分別追蹤的事。
