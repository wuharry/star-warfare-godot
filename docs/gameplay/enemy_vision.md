# 固定最高階 AI 與視線潛行

更新日期：2026-09-29。

## 敵人的戰鬥能力統一使用原本 elite 設定

戰役與 THE EXPANSE 共用 `GameState.ENEMY_AI_PROFILE`，設定畫面不再提供難度選項。讀取舊存檔時忽略 `settings.difficulty`，下次正常存檔不再寫入；其他設定保留。

這項改動統一 AI 的反應、預判、側翼與出招速度。敵人的原始生命、傷害、獎勵、關卡倍率，以及 `is_elite` 強化個體仍各自保留。例如普通 crawler 不會因為使用最高階 AI，就自動獲得強化個體的生命倍率。

| 戰鬥參數 | 固定值 |
| --- | ---: |
| 反應時間 | 0.18 秒 |
| 預判射擊倍率 | 1.0 |
| 瞄準散布係數 | 0.018 |
| 近戰蓄力 | 0.24 秒 |
| 同時持有攻擊許可的普通敵人 | 7 |
| 攻擊間隔倍率 | 原始間隔 × 0.82 |

Boss 延續獨立出招，不占普通敵人的攻擊許可；同樣受視野與遮蔽物限制。

## 敵人必須先看見玩家，才能交戰

`WarfareEnemy` 先判定距離、水平視角，再從眼睛向玩家胸口與頭部投射射線。任一射線未被世界碰撞層阻擋，就算看得見；因此完全躲在高牆後可以避開視線，露頭則仍可能被發現。

| 可調參數 | 初始值 | 意義 |
| --- | ---: | --- |
| `sight_distance` | 28 公尺 | 最遠感知距離 |
| `sight_angle` | 110° | 正前方左右各 55° |
| `detection_time` | 0.35 秒 | 從未警戒到交戰所需的可見累積時間 |
| `search_duration` | 6 秒 | 失去視線後的追查時間，包含走向最後目擊位置 |

以上是本專案的初始調校值，不是原版遊戲數據。參數位於 `scripts/game/enemy.gd` 的 export 欄位。

```text
未發現（原地警戒，不朝隱藏玩家轉身）
  → 玩家進入視野 → 起疑（短暫露面後躲回掩體，可讓懷疑衰退）
  → 可見時間足夠 → 交戰（使用最高階戰術 AI）
  → 失去視線 → 搜尋最後目擊位置，抵達後轉身查看
      ├─ 再次看見玩家 → 交戰
      └─ 搜尋時間到 → 未發現
```

敵人生成時採用獨立的隨機朝向，不會先讀取玩家位置並面向玩家。未發現時為站崗，尚未加入巡邏路線。

## 失去視線後不再讀取玩家即時位置來追蹤

導航改用 `last_seen_position`。玩家在牆後向別處移動，敵人仍只去舊位置；隱藏期間也不更新預判射擊的速度，重新發現時重設速度取樣，避免把一段不可見的位移當成瞬間高速移動。

玩家命中未交戰的敵人，會讓該敵人轉向命中當下的攻擊者位置並開始搜尋；這不會授予持續的穿牆視線。失去視線會取消待發的近戰、停止前撲 tween 並歸還攻擊許可，近戰落點及 Boss 出招也受遮蔽物判定約束。

## 這一版提供視線潛行，任務規則仍照原本模式運作

- 尚未加入蹲伏、腳步／槍聲聽覺、敵人互相通報、可見視野扇形或發現指示 UI。
- 只有世界碰撞層上的物件會遮蔽視線；透明裝飾是否遮蔽，取決於它的碰撞設定。
- 戰役仍須擊敗波次敵人才能過關。例如繞過一隻未警戒的怪可以避免當下交戰，但不會把它計為已擊殺。
- 尚未完成手機效能量測與整場任務的難度調校；不以邏輯測試推定最終遊玩手感。

## 驗證覆蓋感知、戰鬥及舊存檔

| 檢查 | 覆蓋內容 |
| --- | --- |
| `enemy_vision_test.tscn` | 真實碰撞射線、前後／邊界視角、距離、高低掩體、起疑、追查、重新發現、受傷警戒、近戰取消、四種敵人 |
| `enemy_ai_test.tscn` | 固定最高階參數、攻擊許可、蓄力閃避、預判射擊、側翼 |
| `settings_test.tscn` | 舊難度值讀取、移除設定寫入、保留其他設定 |
| `recovered_data_test.tscn` | 原始生命／傷害／獎勵，以及固定 AI 的攻擊間隔倍率 |
| `expanse_test.tscn` | 大地圖仍能建立，使用相同攻擊許可上限 |
| `menu_visual_capture.tscn -- --options-only` | 實際渲染移除難度選項後的設定畫面 |

執行例：

```sh
godot --headless --path . res://tests/enemy_vision_test.tscn
godot --path . --rendering-method gl_compatibility res://tests/menu_visual_capture.tscn -- --options-only --output-dir=res://test_output/enemy_vision --viewport=1280x720 --locale=zh_TW
```
