# Star Warfare 2: Thunder Armor (Reference Assets)

## 說明
本目錄存放從《Star Warfare 2: Payback》（星際異種 2）中提取之 **Thunder / Storm 套裝（Avatar06）** 原始美術資源，作為 **Set 06 (Storm Thunder)** 商業化重塑與拓撲設計之幾何結構與貼圖配色參考。

## 檔案清單
### 1. 3D 模型 (`models/`)
- `sw2_thunder_head.obj` - 頭盔網格 (Mesh)
- `sw2_thunder_body.obj` - 胸甲/軀幹網格 (Mesh)
- `sw2_thunder_hand.obj` - 手臂/拳套網格 (Mesh)
- `sw2_thunder_foot.obj` - 腿部/戰靴網格 (Mesh)

### 2. 貼圖材質 (`textures/`)
- `sw2_thunder_head.png` - 頭盔貼圖 (512x512 RGBA)
- `sw2_thunder_body.png` - 胸甲貼圖 (512x512 RGBA)
- `sw2_thunder_hand.png` - 手部貼圖 (512x512 RGBA)
- `sw2_thunder_foot.png` - 腿部貼圖 (512x512 RGBA)
- `sw2_thunder_fx_01.png` - 驚雷技能光效貼圖 (512x512 RGBA)

## 遊戲原始數據參照
- **套裝代號**：Suit 06 / Avatar06
- **套裝名稱**：Storm（驚雷 / 風暴）
- **技能名稱**：Thunder（全傷害 +50%、移動速度 +2，持續 15 秒）
