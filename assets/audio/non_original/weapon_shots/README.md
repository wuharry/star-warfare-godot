# Machinegun shot pulses

Derived from the corresponding `assets/original/audio/machinegun/*_FiringSound_02.wav` recordings; these are edited source recordings, not newly licensed audio.

Each file uses the first 45 ms of the loop with a 2 ms linear fade-in and 12 ms fade-out. This deliberately short firing pulse is played once per successful shot so the long recording no longer dictates firing cadence. Original recordings remain unchanged. M-27B1 and M-Z7B2 use their corresponding sources even if those recordings sound alike.

Audition weapon balance and loudness in-game before final audio approval.
